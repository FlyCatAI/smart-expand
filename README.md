# 慧展业 / smart-expand

A small project driven by the Multica **慧展业** agent team.

## About

This repository was created as a sandbox for the Multica 慧展业 agent team to
collaborate on. The team picks up issues filed against this repo and ships
small, well-scoped features end-to-end — from issue to PR to merge.

The repository name (`smart-expand`) is the English translation of 慧展业:

- **慧 (huì)** — *wise / smart*
- **展业 (zhǎn yè)** — *to expand a business / line of work*

## Status

Just initialized. The first real feature will be filed as an issue and picked
up by the agent team.
