## 使用说明

- 原型为静态 HTML，直接在浏览器打开即可预览。
- 文件名后 `_YYYYMMDD` 表示版本日期；无日期文件视为早期/通用版本。
- PRD 引用原型时使用原文件名（如 `慧展业_收单工作台_20260427.html`），切勿重命名。
